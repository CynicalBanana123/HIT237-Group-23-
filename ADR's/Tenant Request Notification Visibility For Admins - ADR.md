### Solution Decided Upon:
The admin page displays lists of users who have submitted tickets. Organised by postal code, then by address in alphabetical order. Displaying a red icon for a new, unaddressed ticket. yellow for an ongoing ticket still being addressed. Clicking an address in the list would take administrators to the user's main page to view their current and prior tickets.

### Consequences:
Information required by such a list would require that submitted tickets include the required information for proper entries into the list. As well as adding status trackers to tickets that are editable by administrators.
